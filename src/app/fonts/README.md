# Fontes locais

Os ficheiros `geist-sans.woff2` e `geist-mono.woff2` são cópias locais das fontes
Geist incluídas no pacote `next@16.4.0`. Mantê-las no repositório evita qualquer
pedido à Google Fonts durante `next build` e mantém staging e produção visualmente
idênticos mesmo sem acesso à Internet.
